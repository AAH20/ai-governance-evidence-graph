# Contributing

New claim patterns require bounded context, ownership, supporting and contradicting evidence paths, expiry and reassessment triggers. Regulatory mappings require an authoritative source, exact version, operator role, jurisdiction, applicability date and qualified reviewer.

Do not use “certified,” “legally compliant” or claims of standards-body endorsement. New evidence adapters must document trust boundaries and include tampering, staleness and environment-mismatch tests.

Run `python -m unittest discover -s tests -v` before submitting.
